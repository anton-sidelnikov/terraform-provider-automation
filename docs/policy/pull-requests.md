# Pull Request Policy

Policy ID: pull-requests  
Status: Adopted  
Version: 1  
Adopted: 2026-08-06

## 1. Issue and scope

An approved issue is required and referenced with `For #<issue>`. SDK pull requests contain one route unless maintainers approve an explicit exception.

## 2. Branch and history

Automation uses an `agent/*` branch from a captured base SHA. Review changes append commits; force pushes and branch replacement are forbidden.

## 3. Evidence

The body includes documentation links, policy versions, citations, validation, hashes, source revisions, classification, and machine-readable automation metadata.

## 4. Continuation

Feedback updates the existing branch and pull request. Automation never closes and recreates a pull request to avoid review.

## 5. Review checklist

- [ ] Issue, documentation, and evidence are linked.
- [ ] Scope is one route or an approved exception.
- [ ] Review updates preserve branch and history.
